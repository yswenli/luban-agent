# 配置与建库（newproject-setup-db）

> 「新建项目」插件原子技能 · 对应 **Step 4** · **M4-P1 骨架版**（执行脚本在 M4-P6 补齐）。

## 何时使用

- 主 skill `newproject-create` 的第 4 步；
- 或**仅重建数据库**（例如脚本改动后重跑）。

## 执行（纯本地步骤：调用共享能力层，不走 MCP）

调用 `INewProjectService.SetupDatabaseAsync`，内部顺序：

1. 生成 / 更新各端配置文件（连接串、数据库名、端口等，按 `DatabaseOptions` 与项目缩写推导）。
2. 若 `ScriptPath` 提供了建库脚本，则执行之（数据库类型由 `Provider` 决定，默认 `mysql`）。
3. 回写档案：`Database.Created = true`，并把结果追加到「Agent 操作记录」。

> 本地步骤与向导面板共用同一 `INewProjectService` 实例：向导里点「执行建库」和本 skill 走的是同一段代码。

## 结果

- 配置文件已就位，数据库已创建（或明确说明「仅写配置、未建库」）。
- 操作记录区出现该步时间线条目（动作 / 参数摘要 / 结果 / 耗时）。

## 失败处理

- 连接失败 / 权限不足：给出**可操作**的提示（检查连接串、账号权限、数据库服务是否可达），并保留重试入口。
- 脚本部分失败：停在失败语句位置，已执行的语句不自动回滚，提示用户确认后再重跑。
- 任何情况下**不回显**账号口令之外的敏感信息到对话与日志。
