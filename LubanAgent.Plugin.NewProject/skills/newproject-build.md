# 编译检查（newproject-build）

> 「新建项目」插件原子技能 · 对应 **Step 5** · **M4-P1 骨架版**（执行脚本在 M4-P6 补齐）。

## 何时使用

- 主 skill `newproject-create` 的第 5 步；
- 或**仅重新编译**（改代码后复验）。

## 执行（纯本地步骤：调用共享能力层 + 宿主进程白名单内的 `dotnet`）

调用 `INewProjectService.BuildAsync`，内部顺序：

1. 对 Step 1 所选的**每个端**，在其本地目录执行 `dotnet build`。
2. 汇总各端结果（成功 / 失败、错误数、关键错误摘要）。
3. 结果写入档案与「Agent 操作记录」。

> 执行外部进程受宿主进程白名单约束（PRD §3.7：`dotnet` / `git`），越界调用会被运行期拦截并记为 `Disabled`。

## 结果

- 逐端编译结论一目了然；**失败阻断后续步骤**（Step 6 / 7 不自动继续），但**保留已生成代码**，不做回滚。

## 失败处理

- 编译错误：给出**出错文件 / 行号 / 错误码**摘要，并提示可让 Agent 就地修复后重试本步。
- 缺 SDK / 还原失败：提示目标框架与 SDK 要求（本项目统一 `net10.0`）。
- 严禁用「跳过编译」之类话术糊弄：编译失败就是失败，如实上报。
