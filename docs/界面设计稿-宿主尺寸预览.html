Web 插件硬约束与导航边界

同源无 sandbox iframe，Cookie 自动携带；插件页只占主内容区。entryAssembly 必填且入口实现 IPlugin，程序集只能依赖 LuBan.AIAgent；webPage 须在 web 下且防穿越；MIME 仅白名单（mjs / json / map / wasm / woff 不可用）；web 子目录名不得与宿主 controller 同名（14 个保留名，file 尚未纳入拦截）；POST 用 payload 包裹、响应 ApiEnvelope；hash 路由无 SPA 回退；system 特权动作调不到，同源 Cookie 却对全部非特权控制器有效——插件前端只调白名单端点，不得调 MCP 保存、Provider 保存、工作区删除；iframe 以镜像目录为基准，调宿主 REST 须写绝对路径；升级换新 stamp，RequiresRestart 为真须重启宿主才生效；卸载删除失败只留半删目录。
